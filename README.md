# -Compiladores-Lab1
Este repositório contém as atividades do LAB 1, voltadas para a compreensão e prática da etapa inicial de um compilador: o Scanner (Analisador Léxico). As tarefas envolvem desde a análise de fluxos de caracteres até a criação de um mini-scanner, com exemplos em Bash, Python e Java, para ilustrar a identificação de lexemas e geração de tokens.
